# Level 0 → 1

## Objective
Find the password for the next level.

## Steps
1. Log in to Bandit and list the files in the current directory.
2. Read the file that contains the password.

```bash
ls
cat <filename>
```

The password was stored in a readable file in the current directory.

## Password
```text
6y2kwnwK6grgvwvpvLaa2T1cpFEKOhNR
```

## What I Learned
- `ls` is used to list files and directories.
- `cat` is used to display the contents of a file.
- The password for the next level is often stored in a plain text file in the current directory.
- Basic Linux navigation is essential when working through the wargame.
