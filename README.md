# OverTheWire Bandit — Write-ups

My personal notes and write-ups while working through the OverTheWire Bandit wargame.

> Goal: practice Linux fundamentals, file handling, and command-line problem solving.

## Connecting to Bandit

```bash
ssh bandit0@bandit.labs.overthewire.org -p 2220
```

After each level, use the password found in that challenge to log into the next account, for example:

```bash
ssh bandit1@bandit.labs.overthewire.org -p 2220
```
